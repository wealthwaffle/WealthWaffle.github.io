🏛️ Épargne pension & Épargne long terme

🌱 Débutant

Les deux enveloppes les plus importantes — et pourtant souvent sous-utilisées. Chacune donne droit à une réduction d'impôt de 30%.

🚀 Avancé
🏛️ Épargne pension — Option AMax · Réduction · Code 1361/2361
🏛️ Épargne pension — Option BMax · Réduction · Code 1361/2361
💼 Épargne long terme (ELT)Max · Réduction 30% · Code 1480/2480 · Cumulable avec EP
⚠️ Zone piège épargne pension : verser entre et donne une réduction moindre. Choisir : soit ≤ (30%), soit ≥ (25%).
Source 🔗 SPF Finances — Épargne pension

💼 Frais professionnels

🌱 Débutant

En tant que salarié, tu peux choisir entre le forfait légal (calculé automatiquement) ou les frais réels si tu peux justifier un montant supérieur.

🚀 Avancé
Forfait légal salarié30% des revenus · Code automatique
Frais de déplacement domicile-travailVoiture : 0,17€/km · Transport commun : exonération · Code 1257
Bureau à domicile% surface × charges réelles ou forfait 10€/m² · Code 1258
Matériel informatique (usage pro)Amortissement sur 3 ans · Code 1258
Frais de formationFormations liées à l'activité professionnelle · Justifier
Repas d'affaires (salarié)Non déductibles à l'IPP belge — sauf contrat collectif
💡 Le forfait légal est souvent suffisant en dessous de 50.000 € de revenus. Calculer au réel uniquement si les frais justifiés dépassent clairement le forfait.

🏠 Habitation — bonus et prêts

🚀 Avancé
Bonus logement Flandre (anciens prêts)Maintenu pour contrats ≤ 31/12/2023 · Code 3370
Chèque habitat WallonieSupprimé pour nouveaux achats depuis 2022 · Maintenu pour anciens contrats
Primes rénovation PEBNon déductibles IPP — mais crédit d'impôt possible selon région
Assurance Solde Restant DûPeut entrer dans l'ELT (code 1480) si contrat mixte

Les avantages fiscaux liés à l'habitation sont largement régionalisés depuis 2015. Se référer directement à la région compétente selon le domicile au 1er janvier de l'exercice d'imposition.

🎁 Dons — jusqu'à 20% du revenu imposable

🚀 Avancé
Dons à ASBL agréées60% de réduction · Minimum 40 € par an · Max 20% revenu imposable · Code 1394
Dons aux universités belges60% de réduction · Mêmes conditions · Attestation fiscale obligatoire
💡 Un don de 100 € à une ASBL agréée coûte réellement 40 € après réduction fiscale. La liste des organismes agréés est sur finances.belgium.be.

✅ Checklist — avant de soumettre ta déclaration

1
Épargne pension : as-tu versé le maximum optimal ? (≤ ou ≥ )
2
ELT : as-tu utilisé ton enveloppe épargne long terme séparée ?
3
Frais professionnels : forfait ou réels — as-tu comparé ?
4
Garde d'enfants : as-tu déclaré toutes les attestations ?
5
Dons : as-tu toutes les attestations des ASBL (arrivées début janvier) ?
6
Droits d'auteur : si tu es développeur/créatif, as-tu vérifié l'éligibilité ?
7
Plus-values : as-tu des PV à déclarer au-delà de l'abattement ?
8
Comptes étrangers : as-tu déclaré tous tes comptes à la BNB et dans ta déclaration IPP ?
La combinaison optimale pour un salarié belge Épargne pension ( remboursés) + ELT (~152 € remboursés) + frais garde enfant + dons = souvent 800 à 1.500 € de réduction d'impôt supplémentaire par an. En 5 minutes de plus sur la déclaration. La plupart des Belges ne prennent pas les 45 minutes pour vérifier leurs droits réels.
